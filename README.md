## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/dhruvipatel-90/Disney-Website-front-end-.git
```

### 2. Navigate to the project folder

```bash
cd Disney-Website-front-end-
```

### 3. Run the project

If the project uses plain HTML, CSS, and JavaScript, open the main `index.html` file in your browser.

If it uses a framework or build tool, follow the setup instructions for that technology.
